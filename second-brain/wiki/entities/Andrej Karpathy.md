# Andrej Karpathy

**身份**：LLM Wiki 概念的提出者。前 Tesla AI 总监、OpenAI 创始成员之一
（本文档只记录与库里内容相关的事实，不做额外补充）。

## 在这个库里的角色

- 他写了一份公开的 **[[wiki/concepts/LLM Wiki]]** 架构说明（GitHub gist，
  标题就叫 *LLM Wiki — A pattern for building personal knowledge bases using LLMs*，
  发布 2026-04-04）。
- 这份文档的定位很特别：**它是一份"点子文件"，明确说是给人复制粘贴给自己的 LLM Agent 用的**。
  它只讲高层思路，具体实现由你的 agent 跟你一起长出来。
- 他在文档里点名了几个 agent 作为例子 —— OpenAI Codex、Claude Code、OpenCode / Pi。
- 他的公开入口：
  - 推文 https://x.com/karpathy/status/2039805659525644595
  - gist https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f

## 他说过的几句关键的话

> **Obsidian 是 IDE，LLM 是程序员，wiki 是代码库。**

> 人类放弃 wiki，是因为维护成本增长得比价值快。

> （关于 Memex）Bush 没解决的那部分，是谁来做维护。LLM 把这个接住了。
